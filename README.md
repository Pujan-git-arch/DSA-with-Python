DSA — Data Structures & Algorithms
=================================

Overview
--------
This folder contains short Python implementations and exercises for common data structures and algorithms used in learning DSA. Files are organized by topic; each subfolder focuses on one concept with small example programs and exercises.

Contents
--------
- Array/: array exercises (`exercise1.py`, `exercise2.py`, `exercise3.py`).
- BinarySearch/: binary search examples and recursive implementations (`exercise1.py`, `learn.py`, `usingrecursion.py`).
- BinarySearchTree/: BST learning scripts (`learn.py`, `learn2.py`).
- Graph/: graph algorithms and examples (`learn.py`).
- HashTable/: hash table exercises and collision handling (`collison_handling.py`, `exercise1.py`–`exercise4.py`, `learn1.py`).
- LinkedList/: linked list implementations and a doubly-linked example (`doubly.py`, `learn.py`).
- Queue/: queue exercises and learning notes (`exercise1.py`, `exercise2.py`, `learn.py`).
- Sorting_Algorithms/: implementations of sorting algorithms organized by algorithm:
  - BubbleSort/BubbleSort.py
  - InsertionSort/InsertionSort.py, InsertionsortExercise.py
  - MergeSort/mergesort.py, exercise.py
  - Quicksort/Quicksort.py, QuicksortExercise.py
  - Selectionsort/selectionsort.py, exercise.py
  - Shellsort/shellsort.py, exercise.py
- Stack/: stack exercises and notes (`exercise1.py`, `exercise2.py`, `learn.py`).
- Tree/: tree exercises and learning notes (`exercise1.py`, `exercise2.py`, `learn.py`).

How to use
----------
- Run individual examples with Python: `python path/to/file.py`.
- Many files are small exercises; read the top of each file for usage notes and expected input.
- To run a folder's exercises, open the file you want to run in your editor and execute it with your Python interpreter.
